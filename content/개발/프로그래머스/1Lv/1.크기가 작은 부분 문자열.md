title: "크기가 작은 부분 문자열"
---

> [!question] 문제 설명  
> 숫자로 이루어진 문자열 t와 p가 주어질 때, **t에서 p와 길이가 같은 부분문자열 중**에서,  
> 이 **부분문자열이 나타내는 수가 p가 나타내는 수보다 작거나 같은 것이 나오는 횟수를 return**하는 함수solution을 완성하세요.
> 예를 들어, `t="3141592"`이고 `p="271"` 인 경우, `t`의 길이가 3인 부분 문자열은 314, 141, 415, 159, 592입니다. 이 문자열이 나타내는 수 중 271보다 작거나 같은 수는 141, 159 2개 입니다.

> [!Example]- 풀이 & 소스코드
>
> ```js title="JS"
> function solution(t, p) {
>   //t[0]부터 p의 길이만큼 짤라서 p의 값과 비교.
>   var answer = 0
>   for (let i = 0; i < t.length; i++) {
>     if (t.slice(i, p.length + i) <= p && t.slice(i, p.length + i).length == p.length) {
>       answer++
>     }
>   }
>   return answer
> }
> ```
>
> ```java title="Java"
> class Solution {
>    public int solution(String t, String p) {
>        int answer = 0;
>        for(int i =0; i<=t.length()-(p.length()); i++){
>            // 1.Integer.parseInt는 `10자리 이하 숫자만 처리`할 수 있어서 인자가 크면 런타임에러남
>            // if(Integer.parseInt(t.substring(i,i+p.length()))<=Integer.parseInt(p))answer++;
>            // 2.Long.parseLong로 하면 더 큰 숫자에 대처는 되지만 느림
>            // if(Long.parseLong(t.substring(i,i+p.length()))<=Long.parseLong(p))answer++;
>            // 3. str.compareTo()로 크기 비교.
>            if(!t.substring(i,i+p.length()).compareTo(p)) answer++;
>        }
>        return answer;
> 	    }
> 	}
> ```



- ##### Integer.parseInt()

  _String타입의 숫자를 int타입으로 변환해줌_

      Integer.parseInt("123"); // 123

- ##### Long.parseLong()

  _String타입의 숫자를 Long타입으로 변환해줌_

      Long.parseLong("123"); // 123

- ##### compareTo()

  _객체의 크기(순서)를 비교함_ ()

      str1.compareTo(str2)
      - str1이 str2보다 "작으면" 음수(-)
      - str1이 str2와 "같으면" 0
      - str1이 str2보다 "크면" 양수(+)
