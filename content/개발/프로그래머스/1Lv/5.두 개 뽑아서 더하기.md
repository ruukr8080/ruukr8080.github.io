> [!question]+ 문제 설명
> 정수 배열 numbers가 주어집니다. numbers에서 서로 다른 인덱스에 있는 두 개의 수를 뽑아 더해서 만들 수 있는 모든
> 수를 배열에 오름차순으로 담아 return 하도록 solution 함수를 완성해주세요.
>
>> - numbers의 **길이**는 2 이상 100 이하입니다.
>>      - numbers의 **모든 수**는 0 이상 100 이하 입니다.
>
>   > [!warning] **입출력 예**
>   >
>   > | numbers | result  |
>   > | ------- |  ------- |
>   > | [2,1,3,4,1]   | [2,3,4,5,6,7] |
>   > | [5,0,2,7]   | [2,5,7,9,12] |

>> 1. 서로 다른 인덱스에 있는 두개의 수를 뽑아 더한다.➡️ 2중 for문으로 모든 조합의 합을 구함.^jscode  
>> 2. 더한 값들은 중복이 되면 안됨 + 오름차순으로 정렬 ➡️ `Set()`으로 저장하여 중복을 방지 + `sort()`로 정렬하기 위해 `Array.from()`을 사용하여 Set객체를 일반 배열로 변환.
>>
>>       `Set()` `Array.from()` `sort()`
>>  ```js
>> function solution(numbers) {
>>    let sum = new Set();
>>    
>>    for(let i =0; i<numbers.length; i++){
>>        for(let j =i+1; j<numbers.length; j++){
>>            sum.add(numbers[i]+numbers[j])
>>        }
>>    }
>>    return Array.from(sum).sort((a,b)=>a-b);
>>}
>> ```
